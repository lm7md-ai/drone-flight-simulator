# 🚁 محاكي الدرون الواقعي المتكامل ثلاثي الأبعاد (AAA Open World 3D Drone Simulator)

مشروع محاكي طيران متكامل فائق الواقعية لطائرات الدرون السباقية (FPV Racing Quadcopter) في عالم مفتوح غني بالتفاصيل والتفاعلية، مع دعم كامل لمحرك **Unity** وخدمات **Unity Gaming Services (UGS)** عبر نظام `/build-live-game`.

---

## 🌟 التحسينات الشاملة (AAA Upgrades)

### 1. هيكل درون واقعي فائق التفاصيل (Realistic Aerodynamic Quadcopter)
- **هيكل أحادي كربوني (Carbon Monocoque Chassis)**: صفيحة أساسية من ألياف الكربون مع قمرة انسيابية (Aerodynamic Canopy) بألوان متعددة.
- **كاميرا FPV عالية الدقة (Dual HD Camera)**: مع عدسات زجاجية عاكسة ومؤشر LED أحمر لتسجيل الفيديو (REC LED).
- **محركات بروشلس احترافية (Brushless Motors)**: مع فتحات تبريد وملفات داخلية وصواميل تثبيت (Prop Nuts) وقواعد هبوط TPU ماصة للصدمات أسفل كل محرك.
- **مراوح ثلاثية الشفرات (Tri-Blade Airfoil Propellers)**: مع تأثير تمويه الحركة الدورانية السريعة (Motion Blur Disc) يتكثف تلقائياً مع زيادة السرعة.
- **بطارية LiPo 4S حقيقية**: مع أحزمة تثبيت ومقبس XT60 الأصفر، وهبوط جهد واقعي (Voltage Sag) عند التسارع العالي.
- **هوائي خلفي 5.8GHz Lollipop**: مع أسلاك وهوائيات استقبال مزدوجة.
- **شريط إضاءة خلفي تفاعلي (Addressable RGB LED)**: يضيء حسب المظهر المختار ويتفاعل مع دواسة السرعة.
- **مظاهر وألوان متعددة (Drone Skins)**: التبديل الفوري بين (Cyberpunk Neon, Stealth Carbon, Racing Orange, Electric Cyan).

### 2. عالم مفتوح متكامل وغني بالبيئات والتفاصيل (750m Interactive Multi-Biome World)
- **منطقة المطار والمدرج (Airport District)**: مدرج أسفلت متكامل بعرض 26 متر وطول 95 متر مع خطوط بيضاء مرسومة، حظيرة طائرات (Hangar)، وبرج مراقبة جوي (Air Traffic Control Tower).
- **حي ناطحات السحاب والمدينة (City & Skyscraper District)**: 16 ناطحة سحاب شاهقة مع منصات هبوط طائرات على الأسطح (Rooftop Helipads) لتمارين المناورة والنزول السريع.
- **جسر معلق فوق الوادي (Suspension Bridge & Canyon)**: جسر ضخم بأبراج حمراء تعبر الوادي مع سيارات وشاحنات تتحرك على الطريق السريع بسرعة حقيقية.
- **بحيرة جبلية تفاعلية (Mountain Lake)**: سطح مائي عاكس مع شاطئ رملي وانخفاض في التضاريس للطيران المنخفض فوق الماء.
- **مزرعة توربينات الرياح (Wind Farm)**: توربينات هوائية عملاقة تدور أجنحتها باستمرار على قمم الجبال.
- **أشجار وغابات صنوبر**: موزعة في الأودية والتلال.

### 3. نظام تفاعلي متكامل للألعاب والمهمات (Interactive Gameplay Systems)
- **رادار وخريطة مصغرة (Minimap Radar)**: رادار دائري تفاعلي في زاوية الشاشة يوضح موقع الدرون، اتجاه الرأس، بوابات السباق، وبلورات الطاقة.
- **20 بلورة طاقة تفاعلية (Energy Orbs)**: موزعة في أماكن سرية (فوق أسطح الأبراج، داخل حظيرة المطار، أسفل الجسر المعلق، وفوق البحيرة) تصدر أصواتاً ونقاطاً عند جمعها.
- **بوابات السرعة الخارقة (Nitro Boost Rings)**: حلقات نيون نارية تمنح الدرون دفعة سرعة مضاعفة (Boost) لمدة ثانيتين مع صوت اختراق حاجز الصوت!
- **مسار سباق نيون متكامل (12-Gate Circuit)**: يمر عبر المدينة والوادي والبحيرة مع احتساب التوقيت الدقيق وأسرع دورة (Best Lap).
- **نظام الاصطدامات والاهتزاز (Crash & Impact FX)**: تأثير تشويش أحمر للشاشة (Screen Glitch) مع صوت ارتطام عند الاصطدام بالسرعات العالية.

## 🎮 التجربة الفورية في المتصفح (Instant WebGL 3D Simulator)

الملف مفتوح الآن في متصفحك، ويمكنك إعادة تشغيله في أي وقت بفتح:
👉 `Playable_3D_Drone_Simulator.html`

### أزرار التحكم (Controls):
| الزر | الوظيفة |
|---|---|
| <kbd>W</kbd> / <kbd>S</kbd> أو <kbd>↑</kbd> / <kbd>↓</kbd> | قوة دفع المحركات (Throttle Up / Down) |
| <kbd>A</kbd> / <kbd>D</kbd> أو <kbd>←</kbd> / <kbd>→</kbd> | الدوران الأفقي يميناً ويساراً (Yaw Left / Right) |
| <kbd>I</kbd> / <kbd>K</kbd> أو <kbd>Num 8</kbd> / <kbd>Num 2</kbd> | الميلان للأمام والخلف (Pitch Forward / Back) |
| <kbd>J</kbd> / <kbd>L</kbd> أو <kbd>Num 4</kbd> / <kbd>Num 6</kbd> | التدحرج الجانبي يميناً ويساراً (Roll Left / Right) |
| <kbd>C</kbd> | التبديل بين كاميرا FPV وكاميرا التتبع الخارجية (Chase View) |
| <kbd>M</kbd> | التبديل بين وضع التوازن (Angle) والوضع البهلواني الحر (Acro) |
| <kbd>[</kbd> و <kbd>]</kbd> | تعديل زاوية ميلان كاميرا الـ FPV (Camera Uptilt) |
| <kbd>Space</kbd> | دفعة تسارع قصوى للمحركات |
| <kbd>R</kbd> | إعادة وضع الدرون في مدرج الإقلاع |
| زر `مظهر الدرون` | تغيير لون وخامة الدرون (Neon, Stealth Carbon, Orange, Cyan) |

## 🛠️ تشغيل المشروع وتوليده داخل Unity Editor

1. افتح **Unity Hub** واضغط **Add** ثم اختر المجلد:
   `c:\Users\HP\Downloads\neww game`
2. في شريط القوائم العلوي داخل Unity:
   👉 **Tools > 3D Drone Simulator > Setup Open World & Drone**
3. اضغط على زر **`🚀 1-Click Generate Complete Game Scene`**.
4. سيتم بناء العالم التفاعلي والدرون الفائق بكامل مكوناته وحفظ المشهد في:
   `Assets/Scenes/OpenWorldDroneSimulator.unity`.
5. اضغط **Play ▶** للتحليق الفوري!
